# 三角洲行动 (Delta Force) 7.1 音频优化指南

## 游戏特性分析

### 地图和战术

- **地图规模**: 大型开放地图（对标 Warzone / Tarkov）
- **出生点**: 固定，不随机
- **敌人来源**: 360° 全向
  - 被绕后: 敌人出现在身后 (180°)
  - 侧面夹击: 左右两侧 (±90°)
  - 前方交火: 正前方到 45° 范围
  - 高度差: 敌人可能在高地或低地

### 音频需求

| 场景 | 关键需求 | 优先级 |
|------|---------|--------|
| **快速定位** | 瞬间知道敌人方向 | 🔴 最高 |
| **全向覆盖** | 所有方向都清晰 | 🔴 最高 |
| **距离感** | 判断敌人远近 | 🟠 高 |
| **高度感** | 知道敌人楼上/楼下 | 🟠 高 |
| **后方防守** | 绕后敌人可听见 | 🟠 高 |

## 优化策略

### 1. 全向均衡 (核心)

**不是前置增强，而是平衡所有方向的定位精度。**

```
传统 FPS 优化:
前置增强 → 敌人在后方时混淆

三角洲优化:
所有方向 = 1.0x → 敌人从任意方向都清晰
```

**当前增益配置**:

```csharp
前中 (0°):      0.95x  ← 自然中心位置
前左 (-45°):    0.95x  ← 对称
前右 (45°):     0.95x  ← 对称

侧左 (-90°):    1.0x   ← 精确定位最强（ITD/ILD最大）
侧右 (90°):     1.0x   ← 精确定位最强

后左 (-135°):   0.90x  ← 略低但保留信息
后右 (135°):    0.90x  ← 对称

低频 (LFE):     0.25x  ← 低能量，避免混淆
```

### 2. 侧面强化

侧面音源的定位精度最高（物理特性）：
- **ITD** (两耳时间差): 最大，易区分
- **ILD** (两耳音量差): 最大，易感知
- **频谱**: 变化明显

**结果**: 90° 和 270° 的敌人最容易准确定位

### 3. 后置不减弱（关键改进）

**旧策略（错误）**: 后置减弱 50% → 绕后敌人听不清

**新策略（正确）**: 后置保持 90% 增益 → 绕后敌人可清楚听见方向

这对三角洲行动战术来说**很重要**，因为：
- 被绕后是常见战术
- 靠听觉防守后方
- 70% 的胜负由声音定位决定

### 4. HRTF 强度调整

**当前预设值**: 1.2x（中等强化）

| 值 | 效果 | 场景 |
|----|------|------|
| 0.8x | 微弱虚拟化 | 听觉敏感、长时间游戏 |
| 1.0x | 参考标准 | 平衡体验 |
| 1.2x | **推荐** | 三角洲行动 |
| 1.5x | 强虚拟化 | 寻求最大方向感 |
| 2.0x | 极端虚拟化 | 尝试性，可能过度 |

### 5. 环绕声宽度调整

**当前预设值**: 120° (标准)

| 值 | 效果 | 场景 |
|----|------|------|
| 60° | 紧凑 | 方向感密集 |
| 100° | 中等 | 自然 |
| 120° | **推荐** | 三角洲行动 |
| 150° | 开放 | 更分散的环绕感 |
| 180° | 最宽 | 极端分散 |

## EQ 调优指南

### 关键频段

| 频段 | 用途 | 调整 |
|------|------|------|
| **100-500Hz** | 低频定位 | 轻微 (+0~1dB) |
| **1-2kHz** | 方向识别 | 重要 (+1~3dB) |
| **2-4kHz** | **主定位频率** | **关键 (+3~5dB)** |
| **4-8kHz** | 精细定位 | 重要 (+2~4dB) |
| **8-16kHz** | 纹理感 | 轻微 (+0~2dB) |
| **16-20kHz** | 空气感 | 最小化 (0dB) |

### 推荐 EQ 曲线

#### 配置 1: 标准增强 (推荐)
```
100Hz:  0dB   (中性)
200Hz:  1dB   (轻微提升)
500Hz:  0dB   (中性)
1kHz:   2dB   (定位增强开始)
2kHz:   4dB   ⭐ 主定位频率
4kHz:   5dB   ⭐ 最强增强
8kHz:   3dB   ⭐ 精细定位
12kHz:  1dB   (轻微)
16kHz:  0dB   (中性)
20kHz:  0dB   (中性)
```

#### 配置 2: 竞技激进
```
100Hz:  -1dB   (消除低频混淆)
200Hz:   0dB
500Hz:  -1dB
1kHz:    3dB   (强方向感)
2kHz:    5dB   ⭐ 最强
4kHz:    6dB   ⭐ 超强
8kHz:    4dB   ⭐ 强精细定位
12kHz:   2dB
16kHz:   0dB
20kHz:   0dB
```

## 实战调试流程

### 第一步：基础测试 (20 分钟)

1. **打开训练模式**（无伤害）
2. **使用预设 A "全能定位"**
3. **在空地上走一圈**：
   - 前方 (0°) 走动声：应该在正前方
   - 右侧 (90°) 走动声：应该明确在右
   - 后方 (180°) 走动声：应该明确在后
   - 左侧 (270°) 走动声：应该明确在左

### 第二步：方向精度测试 (30 分钟)

1. **蒙眼测试**（推荐）：
   - 让 AI 敌人在不同位置生成
   - 你蒙眼（或看别处）听声音判断方向
   - 转身指向声源
   - 检查准确度

2. **精度评分**：
   - ±15° 以内: ⭐⭐⭐⭐⭐ 优秀
   - ±20° 以内: ⭐⭐⭐⭐ 很好
   - ±30° 以内: ⭐⭐⭐ 良好
   - ±45° 以内: ⭐⭐ 可接受
   - ±60° 以上: ⭐ 需要调优

### 第三步：微调 (需要反复)

**如果方向精度不够**:

```
症状: 左右混淆 (90° 和 270° 定不清)
原因: HRTF 强度可能太低或 EQ 不对
调整: 
  - 增加 HRTF 强度到 1.4x
  - 增加 4kHz EQ 到 +5dB
  - 保持环绕声宽度 120-130°
```

```
症状: 前后混淆 (0° 和 180° 分不清)
原因: 可能需要更多高频
调整:
  - 检查 8kHz EQ 是否 +3dB 以上
  - 考虑激进配置中 -1dB @ 100Hz（消除低频混淆）
```

```
症状: 感觉疲劳听不清
原因: 虚拟化过度或 EQ 过激进
调整:
  - 降低 HRTF 强度到 1.0x
  - 使用舒适长时间预设
  - 让耳朵适应 15 分钟
```

## 故障排除

### 问题: 听不出方向感

**检查清单**:
- [ ] CABLE Input 是否输出到我们的程序？
- [ ] 我们的程序是否在运行并显示"捕获中"？
- [ ] HRTF 强度是否 ≥ 1.0?
- [ ] EQ 是否应用了 2-4kHz 的提升？
- [ ] SK02 音量是否足够大？

**排查步骤**:
```powershell
# 打开 Windows 音量混合器
mmsys.cpl

# 检查 CABLE Input 是否有音量条
# 检查我们的程序输出是否有活动
```

### 问题: 脚步声位置不清楚

**原因**: 可能需要更强的频域增强

**调整**:
```
1. 增加 HRTF 强度: 1.2x → 1.4x
2. 增加 4kHz EQ: +3dB → +5dB
3. 增加 2kHz EQ: +2dB → +4dB
4. 测试 15 分钟让耳朵适应
```

### 问题: 听起来不自然，像"大头"效果

**原因**: HRTF 虚拟化过度

**调整**:
```
1. 降低 HRTF 强度: 1.5x → 1.2x
2. 降低环绕声宽度: 140° → 100°
3. 关闭音乐，玩 5 分钟
4. 让耳朵适应
```

## 注意事项

### 长时间游戏（3+ 小时）

- 使用 "舒适长时间" 预设
- HRTF 强度 ≤ 1.0x
- 每 1 小时休息 10 分钟
- 眼睛放松，听觉需要更多努力

### 竞技比赛模式

- 使用 "竞技精准" 预设
- 在比赛前 1 小时预热
- 坚持使用同一个预设（不要中途切换）
- 记录当前 EQ 和 HRTF 参数（以后保持一致）

### 新用户适应

- **第一周**: 用 "全能定位" 预设适应
- **第二周**: 开始微调参数找到个人最优点
- **一个月后**: 参数稳定，可以竞技使用
