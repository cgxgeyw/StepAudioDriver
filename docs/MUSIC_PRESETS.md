# 音乐预设分类与示例歌曲

内置的「流行音乐」已拆成 8 个更细的分类，音乐预设用一条线框框在一起（不再折叠，全部可见）。每个分类的 EQ 侧重点不同，示例歌曲用于快速判断该选哪个预设。

| 预设 | 声音取向 | 适合的场景 | 示例歌曲 |
|---|---|---|---|
| **男声流行** | 中低温暖、齿音克制；125–2k 轻抬，16k 略收 | 男声华语流行、民谣摇滚人声 | 当爱已成往事（张国荣）、青花（周传雄）、唯一（告五人） |
| **女声流行** | 人声通透、空气感；1–2k 抬升，低频收一点 | 女声华语流行、抒情歌 | 这世界那么多人（莫文蔚）、我只在乎你（邓丽君）、光年之外（邓紫棋） |
| **抒情 R&B** | 暖厚松弛；低频和 1–2 kHz 都有支撑，8 kHz 略收 | R&B、灵魂、慢摇抒情 | Stay With Me（Sam Smith）、Shape of My Heart（Sting）、水星记（郭顶） |
| **摇滚独立** | 鼓点有力、吉他颗粒；低频和 2–4 kHz 增强，中低不浑浊 | 华语摇滚、独立乐队、英伦/另类摇滚 | 故乡（许巍）、黑白色（麻园诗人）、Yellow（Coldplay）、Snow（Red Hot Chili Peppers）、Man Made Paradise（Freddie Mercury）、天空之城（李志） |
| **金属** | 低频紧、攻击性强；250–500 Hz 略收，2–4 kHz 抬起 | 交响金属、工业金属、重型摇滚 | I Want My Tears Back（Nightwish）、Du hast（Rammstein） |
| **舞曲拉丁** | 下潜深、节奏亮；低频和 8–16 kHz 增强 | 拉丁、舞曲、流行电音 | Despacito（Daddy Yankee）、Good Time（Carly Rae Jepsen） |
| **交响史诗** | 西幻交响、大动态；低频与空气感延伸，中频不抢 | 电影/游戏交响、西幻配乐 | Journey of a Lifetime（葬送的芙莉莲） |
| **原声 ACG** | 通透自然、低频克制；只做很轻的 1–4 kHz 提亮 | 指弹、日系/ACG | 流行的云（岸部真明）、Bad Angle（LiSA） |

## 参数对照

- 每个预设现在带自己的 **10 段中心频率、每段独立 Q 值**、以及 **低频/高频搁架**
- Q 范围 0.5–10，每个频段单独设置；不再出现所有预设 Q 都被夹到 0.85 的情况
- BassBoost 是低频倍率，应用时折进 32/64 Hz 两个低频段；表里低频列给的是**倍率生效后的最终增益**
- 增益已明显拉开；自动 preamp 会按最大正增益衰减，所以整体音量可能变化，但音色差是真实的

## 预设现在影响什么

- 10 段 EQ 的**增益、中心频率、Q**
- **低频/高频搁架**：各自的频率、增益、Q
- **BassBoost**：低频倍率，折进 32/64 Hz 低频段
- **HRTF 强度**与**环绕宽度**
- 自动 preamp 会按当前预设最大正增益衰减，避免 EQ 顶爆限幅器

不再出现“所有预设只差 1 dB”的情况；内置预设仍然只读，想微调就切到「自定义」。
